# TrabalhoPratico-Alg2
Trabalho Prático 1 – Indexação Geoespacial e Geometria Computacional Híbrida

Nesse trabalho, serão abordados os aspectos práticos da integração entre estruturas de dados
para tratamento de strings e algoritmos de geometria computacional. Especificamente, serão
explorados aspectos de implementação de árvores de prefixos (Tries ) aplicadas à codificação
Geohash.
O objetivo secundário é fixar o conteúdo teórico e demonstrar sua aplicabilidade em contextos práticos, tais como sistemas de rastreamento de frotas e serviços de geolocalização em
tempo real (ex.: plataformas de entrega e transporte). Entende-se que, ao implementar essas
estruturas, o aluno compreenderá com maior profundidade os detalhes relacionados a essas
estruturas. Além disso, os alunos terão a oportunidade de trabalhar com bibliotecas para
manipulação, processamento e plotagem de mapas e dados geográficos.
